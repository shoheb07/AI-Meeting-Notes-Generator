# AI Meeting Notes Generator

## Overview

AI Meeting Notes Generator is an intelligent productivity application that automatically converts meeting recordings into structured notes, summaries, action items, and key decisions.

The application combines speech recognition and natural language processing to reduce manual note-taking effort.

## Features

* Audio-to-text transcription
* Automatic meeting summaries
* Action item extraction
* Decision tracking
* PDF export support

## Technologies Used

* Python
* Flask
* Whisper AI
* Transformers
* PyTorch

## Installation

pip install flask openai-whisper transformers torch

## Run Project

python app.py
